
# IT Support Home Lab

## Project Overview

This repository documents my hands-on learning and practical exercises in IT Support, Helpdesk, and Service Desk operations.

The project simulates a small corporate IT environment where I practise common IT administration, troubleshooting, user account management, and service desk responsibilities.

It is intended to refresh my existing IT support knowledge and strengthen my practical understanding of modern workplace technologies.

## Technologies and Tools

- Windows Server 2025 Evaluation
- Windows 11 Enterprise Evaluation
- Oracle VirtualBox
- Active Directory Domain Services
- Group Policy
- Microsoft 365 Administration (guided learning and lab exercises)
- Microsoft Entra ID
- Microsoft Intune fundamentals
- PowerShell
- TCP/IP, DNS, DHCP and network troubleshooting

## Lab Objectives

- Configure a Windows Server domain controller.
- Create and manage Active Directory users and groups.
- Configure Organizational Units and Group Policy.
- Join Windows client machines to a domain.
- Practise account provisioning, password resets and access management.
- Study Microsoft 365 user and license administration.
- Troubleshoot common Windows, application, printer and network issues.
- Simulate helpdesk tickets, escalations and knowledge base documentation.

## Project Structure

Each folder contains practical exercises, technical notes, troubleshooting scenarios, and screenshots documenting my progress.

## Disclaimer

This is a personal training environment using fictional users, systems, and data. It is not a production corporate environment.
